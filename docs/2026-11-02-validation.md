## 用户测试发现并修复

允许 Documents 访问后仍显示 `[Errno 1] Operation not permitted`。最小复现证明 Foundation Process 已将 Python 设为进程组首领，再执行 `setsid()` 会失败；不是归档目录未授权。

仅在非进程组首领时建立新会话后，原生启动及已独立会话的回归测试通过；取消任务会结束同组子进程。修复版已重新安装并通过界面扫描。
