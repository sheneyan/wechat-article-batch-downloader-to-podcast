# Mac 口播稿拉取与统一节目

用户确认：Grok 与微信文章共用现有 RSS，节目名称改为“我的订阅”；继续手动选择生成/发布，线上合计最多 20 集。

## 行为

- 音频库顶部显式“拉取口播稿”，不在启动时自动联网拉取。
- 单独保存收件服务的读取地址/密钥，独立于 Grok 写入密钥和 SSH 发布配置。
- SHA256 校验下载文档，按连接身份隔离游标，文档文件名使用 ID 哈希。
- Grok ID 映射为稳定的本地音频 ID；正文原样成为 speech，备注不进入朗读。
- “全部 / 公众号 / 每日X”来源筛选；测试稿默认隐藏，界面和 Python 均阻止试听、生成和发布。
- “查看稿件”只读显示实际朗读正文与单独备注。
- 相同 ID/相同内容重复拉取不产生重复条目；不同内容不覆盖原文，要求修订编号。
- 混合 RSS 保留原微信 GUID；Grok 可没有原文链接，使用独立 GUID 前缀。

- 使用隔离库合成一段 6.8 秒真实 TTS，并完成本地 Publisher/RSS 输出验证；该音频不上传生产服务。

- 代码审查发现的跨服务游标复用、`state`/大小写文件名碰撞及同 ID 内容覆盖均增加回归测试并修复。
