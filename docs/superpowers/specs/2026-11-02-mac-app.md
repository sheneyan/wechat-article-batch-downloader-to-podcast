# 微信文章播客 Mac App

用户在 2026-11-02 聊天中确认将文章批量下载与本地音频/线上节目管理合并。

- 基于 dingaiminGIT/wechat-article-batch-downloader 的 SwiftUI + Go 应用扩展，保留下载、连接微信、恢复代理能力。保留上游 Commons Clause + MIT 许可和来源记录。
- 新增统一「音频库」页面：从归档目录扫描，跨公众号列出标题、来源、日期、本地音频状态、线上状态；支持多选、转换、试听、播放完整音频、Finder 定位。
- 新增「在线节目」页面：从 RackNerd 实时获取最多 20 集、总音频大小；选择本地音频发布前展示将上线/淘汰的具体清单，由用户点击发布执行，不自动上传。
- 本地状态与线上状态分开：未转换、本地已转换、需重新转换；在线、仅本地，线上状态查询失败时显示未知，不能把网络错误当作未上线。
- 订阅 URL 可复制；清楚提示刷新在线列表时间和网络错误。
- SwiftUI 通过子进程调用随包携带的 Python 模块，不开放新的本地 HTTP 端口。复用本机 Python 3.11、ffmpeg、ffprobe、SSH/Tailscale；检查依赖，错误显示在界面。
- App 采用独立 bundle id、独立 Application Support 目录、2142/2143 下载器端口，不覆盖用户已安装的上游 App、配置或记录。导出目录默认用户现有 wechat_archived。
- 一次性复制当前项目内已经生成的完整音频和发布配置到新 App 数据目录；不删除原文件。服务器发布目录/RSS 身份不变。
- 转换/发布期间关闭窗口继续运行；退出前若有任务则提示等待或停止，避免中断任务却误报成功。
- 本次只管理微信文章及其音频；已有普通播客的上海中转、固件与家庭节点继续独立运行。
