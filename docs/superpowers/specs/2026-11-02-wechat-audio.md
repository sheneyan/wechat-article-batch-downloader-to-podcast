# 微信文章播客

已由用户在聊天中确认，2026-11-02 继续实施。

- 所有公众号合为「微信文章」一个节目，每篇文章一集。
- Mac 保存原归档、清理后的朗读文本和 MP3，使用 macOS say 婷婷语音，再用 ffmpeg 转为 24 kHz 单声道 48 kbps。
- 手动选择发布；扫描与转换均不触发上传。服务器最多在线 20 集。
- 发布后超出 20 集时淘汰原在线集合中原文发布日期最早的集；本次选中的集必须上线，即使它的原文日期较早。一次最多选择 20 集。
- 淘汰时先确保新音频完整，再原子替换 RSS，最后删除不再引用的音频；Mac 副本保留。重复发布同一篇不增加集数。
- RackNerd 提供静态 RSS 与 MP3；复用 podcast.zi5.io 的 /wechat/ 专用路径，原播客代理继续工作。路径含随机标识，不加入发现目录。
- 使用 Tailscale SSH 上传，不提供公网写接口。版本冲突中止，失败不替换旧 RSS。
- 上海压缩服务、设备固件、订阅清单、家庭节点同步不在本次改动范围内。
- 首先生成约一分钟本地试听；完整语音和设备播放质量需人工试听确认。
