# Qwen 本地男声接入

目标：将已试听模型接入同一个音色选择、设置试听、文章片段试听和全文生成。用户原有音色继续保留；Qwen 提供 Uncle_Fu、Dylan、Eric，使用独立倍速。安装脚本、配置模板及资源建议提交到用户 fork。

- [x] 独立 tts.json 保存 Python 路径、模型目录、倍速；校验路径、模型类型及数值。
- [x] qwen_worker 在隔离 MLX Python 进程中离线加载模型，分段合成、限制缓存、逐段写 WAV；达到生成长度上限时失败，避免静默截断。
- [x] 复用现有 MP3 转码/原子替换；缓存包含 Qwen 模型与参数签名；错误和取消保留旧成品。
- [x] SwiftUI 音色列表加入三个男声，提供 Qwen 配置/保存/环境检查；所有试听与生成使用统一参数快照。
- [x] setup_qwen.py 安装固定版本运行环境、复用或下载校验模型，写入配置；不提交权重、虚拟环境、用户数据。
- [x] 单测覆盖分段完整性、配置和倍速校验、缓存失效及失败保留；隔离库真实完成两段合成及缓存重用。
- [x] 构建安装后实际检查音色菜单、Qwen 试听/停止，保留用户选择（验收过程中用户已自行切换 Dylan / 2 倍速）；核验签名、推送代码与文档。

验证记录：Python 74 项、Swift 17 项通过；独立代码审查的三项 P2 已修正并增加回归：分词器/运行时缓存签名、损坏分块恢复、固定模型版本。安装脚本在 M1/16 GB 上实际创建独立运行环境并复用现有权重。

隔离库真实完成两段全文生成、缓存复用与 publishable 格式校验：成品 23.6 秒、耗时 207 秒、MLX peak 6.16 GB；不作为独立性能基准。原生 App 实际选择 Qwen、生成短试听并播放（最终观察 Dylan / 2 倍速），以及在 MLX worker 运行时停止任务；worker 退出，临时目录清理。用户原有 26 条文章元数据 SHA 和音频大小保持不变。

App 已构建安装，使用后签名校验通过，无包内 Python 字节码缓存。没有发布验证音频或更改线上节目。模型、环境和本机 tts.json 不提交。
